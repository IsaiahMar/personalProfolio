01 / About

Learning by building

I started programming with Python in my freshman year of high school and haven't stopped since. I studied Computer Software Engineering at Thaddeus Stevens College of Technology, then transferred to Morgan State University, where I'm now in my senior year. Along the way I've built everything from small browser games to a full Laravel application with role-based access, messaging, and volunteer-hour tracking.

What keeps me hooked is that a problem never has just one solution. I like breaking a hard problem into small pieces, trying different approaches, and landing on the simplest one that works.

At Morgan State, I'm an undergraduate researcher in the Human-AI Experience Lab, advised by Dr. Mack. Long term, I want to start my own software company.

Transit System Simulator

A command-line simulator for a train network modeled as a graph. Users add stations and connections, queue passengers, and board trains. The shortest route between stations is found with breadth-first search, and a stack keeps a history of actions.
